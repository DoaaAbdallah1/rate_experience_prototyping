# Rate Experience

A simple Flutter app that lets users rate their experience using an interactive slider and an animated face.

## Preview

[Watch the app preview](https://github.com/DoaaAbdallah1/rate_experience_prototyping/blob/main/assets/images/final_compressed.mp4)

## Features

- Interactive rating slider
- Animated facial expressions based on the selected rating
- Smooth animations and transitions
- Colors change according to the rating
- Simple and clean UI

## Built With

- Flutter
- Dart

## Getting Started

Clone the project:

```bash
git clone https://github.com/DoaaAbdallah1/rate_experience_prototyping.git
```

Navigate to the project directory:

```bash
cd rate_experience_prototyping
```

Install dependencies:

```bash
flutter pub get
```

Run the app:

```bash
flutter run
```
